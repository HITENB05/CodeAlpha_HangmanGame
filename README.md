
# Hangman Game 🎮

## About the Project
This is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

The computer randomly selects a word from a list of five predefined words, and the player has to guess it one letter at a time.

## How to Play
1. Run the Python program.
2. The computer selects a random word.
3. Guess one letter at a time.
4. You get a maximum of 6 incorrect guesses.
5. Guess the complete word to win the game.

## Features
- Five predefined words.
- Random word selection.
- Maximum six incorrect guesses.
- Input validation.
- Console-based gameplay.

## Concepts Used
- Python
- Random module
- While loops
- For loops
- If-else statements
- Strings and lists
- User input and output

## How to Run

Make sure Python 3 is installed.

Open the terminal and run:

```bash
python3 hangman.py
```
